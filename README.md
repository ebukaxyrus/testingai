# Interactive Image Color Explorer

A Streamlit prototype for image color exploration, including a styled upload interface.

## Technology stack
- Python
- Streamlit
- Pillow
- Pandas
- NumPy

## Confirmed functionality
- Includes an image-oriented Streamlit interface
- custom dark styling
- image processing libraries.

## Repository entry point

- `testing.py`: primary inspected Streamlit application.

## Run locally

```bash
git clone https://github.com/ebukaxyrus/testingai.git
cd testingai
python -m venv .venv
source .venv/bin/activate  # Windows PowerShell: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run testing.py
```


## Limitations and responsible use

Avoid promising speech and accessibility features until tested on the live version.
